2 · The delegation loop (standing practice)

Close the loop on every delegation or the fleet silently stops improving. Also recorded in global ~/.claude/CLAUDE.md.

  1. Tag every call — ENFORCED IN CODE since 2026-07-28. gemini.py exits 2 on a missing --tag before spending anything. Shapes: research, doc-format, classify, vision-prescreen, long-digest, copy-draft, code-draft, translate, subagent-fanout, plus smoke for throwaway routing checks. Add --purpose "..." when the first prompt line is a poor title. smith_agent.py and transcribe.py had NO tag flag at all until this date — their runs were structurally untaggable; both now default sensibly.
  2. Verdict after review — verdict.py good|bad|stale "why" --tag SHAPE --model M. Feeds hebbian routing weights: streak 5 = light review, 10 = spot-check. One bad resets it. Use --ts for precision; --model silently targets the most recent run of that name, which has already misfiled one verdict. stale = the output no longer exists to judge; clears the queue without counting as good or bad. Every run now prints a [review] N runs awaiting verdict line to stderr.
  3. Find gaps — gap_report.py monthly, on gym day, or when quota is tight. --refresh re-mines transcripts.
  4. Every bad verdict becomes an agent-gym task before that shape is delegated again.

5 · Key decisions & constraints

  • The model drafts, Claude verifies. Every winner has shipped a bug a review caught.
  • Offload the words, keep the action. Nothing that deploys, commits, posts, or charges — backends hold no credentials.
  • Free clouds may train on your data. Private work stays local. Bibliome and SC Helper ship offline-only.
  • temp 0 is necessary but NOT sufficient for doc conversion. It stopped sentence-dropping; it did not stop proper-noun corruption.
  • Trust has a forgetting curve. The witness re-runs local calls on a schedule that grows with agreement and collapses on disagreement.
  • ollama pull updates weights in place — a trusted model can silently become a different one. Run fleet_check.py after any pull.
  • Stdlib-only is the default, tree-sitter is the one OPTIONAL dependency. pip install tree-sitter tree-sitter-language-pack improves non-Python witness comparison; absent, the code falls back to the previous behaviour and nothing raises. Verified by blocking the import.

6 · Gotchas & lessons

  • Structural validation cannot catch a correctly-formatted wrong word. The biggest fleet defect found to date shipped through a clean validator. More Garlic's 9-locale UI translation was machine-checked for placeholders, brand and tokens and legitimately returned 0 problems — 0 placeholder mismatches and 0 empties across 2,763 strings, all true. Meanwhile "trip" (a grocery run) was rendered as a travel journey in 8 of 9 locales (es viaje, fr voyage, it viaggio, pt-BR viagem, ru поездка, ja トリップ, ko 여행, zh-Hans 行程; de left it as English), zh-Hans carried a hallucinated English word (模拟器 footprint 中相机不可用), and Italian used Spanish que for che. 27 instances reached the live 1.1 build. Any bulk-transform lane — translate, paraphrase, classify — needs a meaning-level spot-check, not just a format check.
  • Pin the vocabulary or the model invents it. The same lane, same model, re-run with a glossary of app-specific terms pinned in the prompt, scored clean: 180/180 correct placeholders, zero banned terms, and it kept quoted button labels byte-identical to the buttons' own translations. The fix was the glossary, not the model. Ledger has both runs — translate bad without, good with.
  • Fleet-grades-fleet works, with two conditions. A different model must do the grading, and every load-bearing claim must be hand-checked before it counts. gemini-pro QA of those translations produced 20 findings with zero false positives on spot-check against the catalog. Without the hand-check it would just be one model's opinion entering the routing table as evidence.
  • Parameter count is not capability — a 3.3 GB local model beat a 7B remote one 6/6 to 0/9. Screenshot triage is the biggest measured offload gap (507M chars), so it was worth testing properly: one full-res app-screenshot crop, exact ground truth, digit strings chosen deliberately because they are qwen3-vl:4b's known weak spot. llava-1.5-7b did not OCR at all — it described an imagined scene ("two birds: a Robin and a Cardinal"), missed a species entirely, invented 60/40 then 50/50 across trials, and hallucinated a "European Robin" at lower resolution. Its wiring was correct (HTTP 200 on the int-array shape), so this was a capability failure, not a config one. The cheapest fleet member won and the offload gap stays open — that is the honest outcome, not a failed experiment.
  • Probing for an error code is not reading the price. Six models were labelled "FREE" on the strength of a 403-vs-200 probe, which only ever proved NOT BLOCKED. Every one of them is priced; Workers AI just has a 10,000 neuron/day allowance (~$0.11) that HARD-STOPS on the free plan. The models API exposes a price property that answers the real question directly — and it was only found while debugging something unrelated. When the question is "what does this cost", read the cost, do not infer it from whether the call succeeded.
  • When a user says a habit won't stick, remove the decision — don't build a better reminder. "I'll never remember to use it" (ADHD, stated directly) killed a three-option on-demand-toggle design outright, including its "Recommended" pick. The fix wasn't a smarter nudge — it was routing the same capability through a decision that was already automatic (Claude's own delegation choice) instead of one that required the user to act.
  • A script can be "wired for cloud" without actually being able to reach one. smith_agent.py's openai backend existed for months (mlx_lm, LM Studio) but hardcoded Authorization: Bearer local — no parameter existed to pass a real key. It looked complete; it had simply never been asked to authenticate. Found only by trying to actually route production work through it, not by reading the code.
  • The ledger is blind to what was never delegated. It only sees delegated work, so gaps live in the Claude transcripts. That is what gap_report.py joins; neither dataset shows a gap alone.
  • A stat that pools unfixable rows with actionable ones stops being read. "858 unreviewed" was 800 permanently-unreviewable legacy rows plus 7 smoke tests plus a real queue of 58. Same for the MISROUTED alarm that kept firing on a route already closed in code. Both were fixed by narrowing the denominator to what someone can actually act on.
  • Exact-match is wrong for code, in every language. The witness compared raw text, so a markdown fence or a type hint read as drift: 18% agreement, every streak pinned at 0, the interval never grew. Python now compares as stdlib ast skeletons with annotations, docstrings and comments normalized away; other languages via tree-sitter. Before the second fix, all six non-Python probes returned False — spacing, semicolons, comments and quote style were indistinguishable from a renamed function or changed logic. DRIFT entries before 2026-07-20 are mostly spurious.
  • tree-sitter is error-tolerant — it returns a tree for nonsense input instead of raising, so any tree carrying an error must be rejected as not-that-language. Otherwise two unrelated blobs both "parse" and compare similar.
  • Operators and keywords are ANONYMOUS tree-sitter nodes. Walking named_children dropped them and made a + b compare equal to a - b — a false AGREEMENT, the dangerous direction for a sensor. Found only because the test carried expected values; eyeballing the output had looked fine.
  • gpt-oss:20b silently corrupts proper nouns in long docs. Reproduced on demand in agent-gym: it wrote Baler for Balancer while keeping BalancerUnit correct in the same section's body — the same shape as the production TarotCore to TatartCore failure. Diff proper nouns and figures against the draft before shipping any converted doc.
  • A doc-fidelity test only discriminates when required output approaches the token cap. A 22-section doc demanded ~1.4-2.1k tokens against a 4000 cap and every model passed. At 54 sections (~3.3k) gpt-oss:20b failed immediately.
  • gpt-oss reasoning eats ~75% of the budget — local doc conversion needs --max-tokens 16384; at 8192 a doc-sized output truncates mid-file.
  • gemini-cli has no --file — pipe file contents via stdin. It is the PAID subscription lane: use it first when the free API is congested (3.8s vs 50s+ measured; the free lane also timed out at 10 min on a doc conversion).
  • Ollama wedge mode: repeated client aborts leave a model stuck "Stopping...". Recovery: kill the llama-server runner PID, or restart Ollama.app.
  • Tags only exist from 2026-07-18. Older history is recovered by per-shape heuristics, so every gap ratio reads as a floor.
  • GLM-5.2's reasoning-budget floor is shape-dependent, not a single fixed number. 1,500-3,000 tokens is enough headroom for a short code-draft answer, but the SAME model on a long-digest task (grounding across a 424-line document, 5 short answers) burned an entire 2,000-token budget on reasoning_content and returned nothing — needed 8,000 to actually answer. Don't reuse a calibrated budget across task shapes; each one needs its own floor, found empirically.
